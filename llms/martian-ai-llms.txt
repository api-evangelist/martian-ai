# Martian

> Martian operates the Martian Gateway, a unified LLM API providing access to 200+ AI models from leading providers (OpenAI, Anthropic, and others) through a single OpenAI- and Anthropic-compatible endpoint. Point the standard OpenAI or Anthropic SDK at https://api.withmartian.com/v1, authenticate with a bearer API key, and address models as provider/model-name. Martian is also an AI interpretability research lab publishing open-source frameworks (ARES, K-Steering, RouterBench) and a model-router / judges SDK.

## APIs

- [Martian Gateway API](https://docs.withmartian.com/gateway): base URL https://api.withmartian.com/v1. Operations: POST /v1/chat/completions (OpenAI-compatible), POST /v1/messages (Anthropic-compatible), GET /v1/models (List Models).

## SDKs

- [martian-python (PyPI)](https://pypi.org/project/martian-python/): Python client library for the Martian API.
- [martian-node (npm)](https://www.npmjs.com/package/martian-node): Node.js library for the Martian API.
- [martian-sdk-python (GitHub)](https://github.com/withmartian/martian-sdk-python): SDK to manage judges and routers.
- OpenAI and Anthropic SDKs work directly against the Gateway base URL.
